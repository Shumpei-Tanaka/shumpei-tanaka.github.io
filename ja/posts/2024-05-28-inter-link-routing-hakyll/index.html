HakyllでRouteを変更した上で内部リンクを使う

HakyllでRouteを変更した上で内部リンクを使う

AuthorShumpei Tanaka
Published2024/05/28
Modified2024/05/28

Hakyll で Route を変更して markdown を pandoc compiler を通してもリンク先は自動で更新されない。

このため、markdown 内の link を手動で書き替えてやる必要がある

Hakyll で定義されている withUrlsを使用するとString->Stringの変換を
各種 URL に適用することができる。これを使用して変更したい URL のみ上書きする。

実装を用いて説明する。

  • parseInnerLinks: parseInnerLink を withUrls ですべての URL に対して適用する
  • parseInnerLink: /postsの接頭辞の url のみ parsePostLink を適用する
  • parsePostLink: #を含んでいる(特定のセクションへのリンク)を考慮した処理。
    #以前の URL を変換し#以後を再結合する
  • convPostUrl: Routeの変更に使用したString->Stringの変換を再利用する。
    Identifierを取得する際、先頭の/が邪魔になるためtailで除去している。
